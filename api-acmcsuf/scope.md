# API Group Scope

The API group is responsible for the backend services and supporting
infrastructure that power ACM CSUF's open source projects.

## Responsibilities

The group focuses on:

- Designing and maintaining APIs used by ACM CSUF services and applications.
- Building backend services and microservices for open source projects.
- Maintaining deployment and operational concerns of said services.
- Supporting other ACM CSUF open source groups when they depend on backend
  services maintained by this group.

## Projects

Projects within the API group should primarily involve backend development,
APIs, data services, or infrastructure closely tied to those systems.

Projects may use different languages and technologies depending on their
requirements. The group is not tied to a particular framework, database, or
programming language.

## Out of Scope

The API group does not own:

- Frontend applications and user interfaces. (Such as **[acmcsuf.com](https://github.com/acmcsufoss/acmcsuf.com)**)
- Standalone Discord bots or automation that do not require a backend service.
- General-purpose infrastructure unrelated to an API group's project. (Like **[acm-server](https://github.com/acmcsufoss/acm-server)**)
- Projects whose primary purpose is unrelated to ACM CSUF's open source
  ecosystem.
